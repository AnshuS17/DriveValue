What is Machine Learning in this context?

Machine Learning allows computers to learn patterns directly from market data rather than using rigid hardcoded rules.

In DriveValue, the Random Forest Regressor creates an ensemble of 100 decision trees. Each tree evaluates subsets of vehicle features (Age, Kilometers, Brand, Fuel Type, Transmission, Engine CC) to predict resale price, averaging predictions to reduce error and overfitting.

Key Viva Presentation Objectives

  • AI Camera Photo Scanner: Uses WebRTC getUserMedia() to capture vehicle photos directly in browser and predict resale price.
  • Data Processing: Applied Scikit-Learn ColumnTransformer with StandardScaler for CC/Mileage/KM and OneHotEncoder for categorical attributes.
  • Model Persistence: Serialized training pipeline using joblib into car_price_model.pkl for fast API inference.
  • Database Integration: Stored car inventory and prediction logs in MongoDB using pymongo.
